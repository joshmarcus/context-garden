# v0.3.0rc15

RC15 removes a controller CPU hot path from idle remote-worker polling. The claim endpoint
now evaluates active run records instead of reparsing the full historical run archive on every
poll. Claim ordering, host capacity, generation fencing, payloads, heartbeat timing, recovery,
and finish semantics remain unchanged.

This is a controller-only release. Existing RC13 workers remain protocol-compatible and do
not require a fleet rollout. RC15 retains RC14's page discovery cache, quiet-tick snapshot
reuse, bounded discovery retry, CI environment correction, split serve/watch topology, and
all RC13 worker materialization and review safeguards.
