# Context Garden 0.3.0rc20

This release candidate repairs two failures observed while operating RC19. Historical branch cleanup now uses bounded remote-reference discovery, so a cleanup pass cannot spend minutes checking old branches one by one while holding the scheduler lock. The final-output supervisor handles FIFO and atomic-replacement handoff without waiting indefinitely, scopes output paths to the current execution, and bounds shutdown while preserving incomplete-output evidence. Codex structured output remains available for native final-result parsing.

The release is built from accepted main commit 3471e86aad71d4929d1a1467fc1e9fb1730e3d0b. Its cleanup repair is PR477, source 8df02641fec6411278b1f471d2fbd45b3968b090; the final-output repair is PR478, source 9945f1f2bf2711adfaa62a01c20d6af758671e76. Both are merged and passed their exact-source CI. Release metadata and these notes are the only changes above the accepted main source.

RC19's original failures remain recorded: cleanup delayed scheduler collection and subsequent dispatch, while authenticated claims, heartbeats and finish continued. Several already-completed model runs needed guarded recovery from a childless supervisor deadlock; their original outputs, source, interrupted exits and accounting are preserved. Earlier candidate review also reproduced inherited output-path mutation and a bounded simulation of unread final-tail loss. Passing later validation does not erase those observations.

Publication requires passing CI for the exact main and release commits, independent source and rollout review, focused deterministic lifecycle tests, and a real RC19-client TCP protocol journey against this candidate. Publication and installation have separate receipts. This release does not claim universal page latency or additional cloud-scenario coverage. The operational rollout covers the existing Ubuntu WSL controller and Linux workers; macOS is not exercised by that rollout.
