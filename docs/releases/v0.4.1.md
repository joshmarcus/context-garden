# context-garden 0.4.1

This release includes all changes on `main` through
`2d4bd6833750c488ac8a6fb5ffd2b6d4ef1a0b30`, plus the 0.4.1 version metadata and
these notes.

- Core pages avoid repeated repository and task-design discovery work; observe
  diagnostics fit pressure and conflict information within the available width.
- Pull request handling reconstructs omitted head repositories and reviews attached
  pull requests at their exact source head.
- Remote runs prepare immutable source metadata before becoming claimable, keeping
  repository preparation out of claim requests.
- Durable SSH runs reconnect to existing work, and `garden attach` provides a command
  for attaching to supported remote runs.
- Worker runtime directories are validated at the target boundary. The configurable
  host fleet maintains a declared healthy worker count within its admission limits.
- Overall acceptance attestations are normalized into per-criterion evidence.

Included pull requests: #507, #508, #509, and #531 through #538. The separate,
unmerged multiplayer and capability-routing stacks are not included.

Python 3.11 or newer is required. Windows usage remains through WSL. No package
dependency change or operator-run data migration is introduced by this release.
The host fleet feature requires explicit configuration and admission; publishing
does not enable it or start workers. Ordinary CI does not establish live cloud or
browser validation.

Install into the intended environment with
`python -m pip install --upgrade context-garden==0.4.1`. To return to the previous
package, install `context-garden==0.4.0` through the same maintenance procedure;
preserve task and run history. Publication does not upgrade or restart any existing
controller or worker.
