# Context Garden 0.3.0rc18

This release candidate includes the accepted idle-claim transport retry correction and merged controller, scheduler and worker repairs through main commit dc84676ee573fbceda33ddc7bf3e1a256e65bdb4. CI passed on that merged main source before this candidate was created.

Changes since the installed RC16 include bounded retries for transient idle-claim failures, coordinated worker-result persistence, workload identity and output ownership corrections, storage and maintenance-state safeguards, review-count policy corrections, and expanded operational reporting.

The main CI repair reconciles import ordering, the expanded operator metrics payload, the architecture map and the sandbox command assertion while preserving execution verification.

RC17 was published but was not deployed. RC18 is a release candidate; Phase 05 remains open and this release does not establish stable-release readiness or phase closure. Publication and activation are recorded separately. The rollout preserves active source and results, existing capacity limits and worker deadlines.

Validation includes exact-commit GitHub CI, focused controller/worker regression tests and an RC16-client-to-RC18-controller compatibility exercise before activation. The operational deployment targets Ubuntu through WSL and the existing Linux worker fleet; macOS is not exercised by that rollout. Optional live-cloud scenarios beyond the existing fleet are not claimed.
