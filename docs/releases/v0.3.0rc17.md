# v0.3.0rc17

RC17 brings the controller and managed workers forward together. It adds durable managed-fleet enrollment, scaling and absolute-deadline handling; bounded recovery for lost or transient idle-claim responses; worker contact and job visibility; stricter exact-source validation receipts; and safer terminal-result collection.

The release also includes layered configuration provenance and editing, failed-CI revision routing, guarded branch cleanup, scheduler-health visibility, clean approved-head merging without a redundant latest-base rebuild, revision-grant accounting, and setup-cache invalidation when scratch-merge workspaces are recreated.

Roll out the controller first and workers sequentially. Compatibility with the preceding worker protocol and preservation of existing run, task and review history are release gates; each worker must be updated to receive the new retry, telemetry, bootstrap and receipt behavior. The rollout must preserve configured fleet size, resource limits and absolute host expiry.

Phase acceptance and release publication are separate decisions. This release does not close a phase or claim that optional live canaries were performed.
