# v0.3.0rc11 durable review feedback handoff

This candidate starts from exact published v0.3.0rc10 and adds only the approved
CG-474 source change. Review comments received while an asynchronous CI analysis,
automated review, or related task-owned run is in flight are retained for the
owning continuation instead of being dropped or dispatched through a competing
revision path.

Feedback ownership is durable across scheduler ticks and restarts. The owning
continuation combines pending trusted review feedback with its result and applies
it once. Head changes, stale continuations, ignored or untrusted comments, revision
limits, existing checks, review gates, and task lifecycle holds remain authoritative.
The release preserves v0.3.0rc10 clean-head merge approval lineage, atomic merge-head
guards, and quiet handling of omitted optional review evidence.

There is no storage migration, state reset, credential rotation, host launch,
resource-limit change, or worker wire-protocol change. Existing v0.3.0rc10 workers
remain compatible with a controller-first deployment. The known worker transport
limitation remains: a worker can abort a claim when a heartbeat or transcript upload
overlaps a controller restart, so active generations and results must be accounted
and reconciled around deployment.

Exact-candidate focused feedback-handoff tests, Ruff, source-diff review,
independent exact-source review, and exact-head full CI are required before this
candidate may be published. Publication and deployment remain separate gated steps.
