# context-garden 0.4.0

This release contains the completed enterprise execution and validation improvements since 0.3.1. It deliberately excludes all multiplayer pull requests, including the in-progress member identity and authorization work in PR504.

- Exact-head command validation and frozen validation plans bind evidence to the intended source and checks.
- Durable SSH sessions retain run state and improve recovery across transport interruptions.
- Missing automated-review verdicts can recover, and terminal tasks retire stale infrastructure holds.
- Local-run worktree activity scans are bounded to avoid spending unbounded time enumerating large trees.
- Ordinary CI tests run across three jobs with a required aggregate gate.
- Reviewed rollout tooling supports controlled upgrades of published versions; enterprise merge validation is documented.

The release is based on non-multiplayer main commit `cecc3a9857ae52dbf730aa6558049fd37105ea01`, with only package-version metadata and these notes added. Multiplayer, public multiplayer serving, task capability routing, SSH attach CLI and closed-task defect annotations are not delivered by this release.

Install with `python -m pip install --upgrade context-garden==0.4.0` in your chosen environment. Python3.11 or newer is required; Windows usage remains through WSL. Publishing this release does not upgrade any running controller or worker. The operator's current deployment remains0.3.0 until a separately authorized rollout.
