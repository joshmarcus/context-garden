# Context Garden 0.3.0rc19

This release candidate restores responsive page accounting by preparing accepted-task history once per calculation and reusing its indexed cohort. It is built from accepted main commit 407a6755cf4b83acf7be0f52679fb7c3a0db27ad and includes the merged idle-claim transport retry and coordinated worker-result persistence repairs.

The exact performance repair reduced a fixed 30,635-event, 597-task metrics calculation from 16.616 seconds to 0.192 seconds under the same one-CPU limit, with byte-identical complete metrics output. Complete read-only pages returned HTTP 200: cold Now 3.78 seconds, warm Now 1.47 seconds and Inbox 1.33 seconds. These are scoped measurements, not a universal latency guarantee.

RC18 was published, but its controller activation detected a real rendering regression and rolled back to RC16. Its original source, validation and failed activation evidence are preserved. No workers were activated on RC18. RC19 publication and deployment are recorded separately.

Release gates include exact-commit CI, independent source and rollout review, focused controller/worker tests, compatible RC16-client protocol journeys and verification of the installed source. The earlier repair-worker full-suite timeout and unidentified failure marker remain preserved separately from subsequent CI results.

Phase 05 remains open. This release candidate does not establish stable-release readiness or phase closure. The rollout preserves source and results, existing capacity limits and worker deadlines. The operational rollout targets Ubuntu WSL and the existing Linux worker fleet; macOS is not exercised by that rollout. Additional live-cloud scenarios are not claimed.
