# context-garden 0.4.2

This focused maintenance release builds on 0.4.1 and backports the PR-approval
improvements from [PR #540](https://github.com/joshmarcus/context-garden/pull/540).
Its code changes are limited to author briefs, review interpretation, and
scheduler handling of review evidence across mechanical rebases.

- Workers receive a clear instruction to address every acceptance criterion.
  Alternate evidence and justified criterion amendments are supported, and reviewers
  consume the replacement outcomes.
- Accepted author evidence and approvals survive recorded, patch-identical
  mechanical rebases, including approvals that arrive after the rebase.
- Pending, stale, or unavailable CI metadata does not create an unchanged coding
  revision. Evidence and infrastructure problems go to operator recovery.
- Dispatch snapshots include current owner-authored context while product source
  remains bound to its recorded revision.

Actual source defects, failed applicable CI, merge conflicts, dependencies, and
owner holds remain actionable. This does not make arbitrary source changes
inherit an earlier approval.

Python 3.11 or newer is required; Windows usage remains through WSL. Package
dependencies and worker protocol are unchanged. Broader multiplayer, capability
routing, and plugin-registry changes merged after 0.4.1 are outside this release.

Install into the intended environment with
`python -m pip install --upgrade context-garden==0.4.2`. To return to the previous
package, install `context-garden==0.4.1` through the same maintenance procedure;
preserve task and run history. Publication does not upgrade or restart an
existing controller or worker.
