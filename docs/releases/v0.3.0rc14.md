# v0.3.0rc14

RC14 reduces repeated task-tree parsing on web navigation. Page requests reuse a
metadata-validated discovery snapshot, copy request-local models before rendering, and
refresh immediately when product, phase, task, spec, or phase-document files change. A
bounded retry prevents persistent concurrent edits from monopolizing a request.

Quiet scheduler ticks also reuse the post-reap task snapshot when its discovery fingerprint
is unchanged, while task writes and external edits still invalidate it. PR 393's two native
CI attempts stopped before tests because the GitHub runner's unrelated Google Chrome apt
index returned inconsistent hashes. RC14 retains that exact source under an independently
reviewed infrastructure disposition and requires its own complete candidate CI. The workflow
removes only the ephemeral runner's Google Chrome apt source before Playwright installs its
Chromium dependencies from the unchanged Ubuntu repositories.

This candidate retains RC13's worker materialization recovery, exact-head review safeguards,
transport compatibility, and deployment fences.
