# v0.3.0rc9 proportionate reviewer judgment and remote review reliability

This candidate starts from exact published v0.3.0rc8 and adds only the approved CG-457,
CG-456, CG-458, and CG-462 changes. Reviewers now choose verification in proportion to the
actual change and may give a clear attestation. Broad paths and keywords no longer force a
generic served replay, screenshot matrix, lifecycle matrix, load schema, checklist, or
description-only source revision. Explicit defects, failed applicable checks, source or
artifact contradictions, and unmet outcomes remain blocking.

Remote review admission is independent of occupied local worker capacity, and queued remote
reviews are protected from duplicate age-timeout recovery. Replay nonces that begin with an
option-like prefix are passed unambiguously to argparse. RC8 review provenance behavior is
retained: resolved and superseded records stay non-actionable while still being visible.

There is no storage migration, state reset, credential rotation, host launch, concurrency
change, or worker protocol change. Exact-candidate focused validation, independent review,
and exact-head GitHub CI remain required before publication and deployment. Existing Phase05
holds remain in force.
